# My Components

> Une librairie de composants **React + TypeScript** conçue avec **Storybook** et **SCSS**, pour créer des interfaces modernes, accessibles et élégantes.  
> Développée dans le cadre de mon apprentissage et de la création de mon futur portfolio.

---

## Stack technique

| Outil | Rôle |
|--------|------|
| **React 18** | Base des composants |
| **TypeScript** | Typage fort et DX optimale |
| **Storybook (Vite)** | Documentation interactive et tests visuels |
| **SCSS** | Styles modulaires et variables globales |
| **tsup** | Build léger et performant |
| **Vitest + Testing Library** | Tests unitaires et d’interaction |
| **Changesets** | Versioning sémantique (à venir) |
